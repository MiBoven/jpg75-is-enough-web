About

JPG75 is Enough

Version 1.8.3

Converts images to JPG at reduced quality — entirely in your browser. No files are ever uploaded to a server; everything happens locally on this device.

EXIF metadata (capture date, camera model, orientation, etc.) is preserved through the conversion when the source file has it.

Naming pattern placeholders

#One digit of a sequential number (repeat for padding, e.g. ##### = 00042)
*Original file name (without extension)
$YYear the photo was taken (or last modified, if unknown)
$MMonth, same source
$DDay, same source
$hHour, same source
$mMinute, same source
$sSecond, same source
$QJPEG quality used (e.g. 75)
Examples
Image##### → 42nd image becomes Image00042.jpg
$Y$M$D_$h$m$s → taken 30.9.2004, 14:05:09 → 20040930_140509.jpg
*_$Q → image named picture.png, quality 75 → picture_75.jpg
