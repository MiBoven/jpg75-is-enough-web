Naming pattern placeholders

#One digit of a sequential number (repeat for padding, e.g. ##### = 00032)
*Original file name (without extension)
$PFolder name, as entered above
$YYear (current, e.g. 2026)
$MMonth (e.g. 08)
$DDay (e.g. 01)
$HHour
$NMinute
$SSecond
Examples
Image##### → 32nd image becomes Image00032.jpg
$P_##### → with folder "ABC", 32nd image becomes ABC_00032.jpg
$Y-$M-$D_##### → 32nd image, processed today → 2026-08-01_00032.jpg
*_tn → image named John.png becomes John_tn.jpg
